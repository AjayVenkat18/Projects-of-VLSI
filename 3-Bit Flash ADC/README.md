# 3-Bit Flash ADC Design using CMOS

## Overview

Designed a 3-bit Flash Analog-to-Digital Converter using CMOS circuits and Microwind.

## Architecture

- Resistor-based voltage divider
- 7 CMOS comparators
- 3-bit priority encoder
- 3-bit digital output

## Tools Used

- Microwind
- SPICE
- CMOS Circuit Design
- MOSFET-level Circuit Design

## Implementation

Implemented the transistor-level CMOS circuits, developed the SPICE netlist, and designed the CMOS layouts using Microwind.

## Simulation

The ADC was simulated using the developed SPICE netlist and the output waveforms were analyzed.

For an input voltage of 1.800 V, the ADC produced the digital output:

`001`
